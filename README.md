# Styrit Audio HiFi DSP downloads

Download installers from [GitHub Releases](https://github.com/Styrit/styrit-audio-hifi-dsp-releases/releases).

For the optional test-signed virtual audio driver, read the
[Windows driver setup guide](WINDOWS-DRIVER-SETUP.md) before preparing Windows or
choosing the driver component. The guide covers test signing, Secure Boot,
memory integrity (HVCI), certificate consent, updates and removal.

Release 0.1.0 is an app-only installer. The optional bundled driver is planned for
0.2.0 and requires internal acceptance before publication. See each release's
notes for the components actually included.
